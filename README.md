## Introduction

This portfolio showcases my skills, projects, and experiences as a software engineer. It includes a hero banner, an about me section, a showcase of my projects, a skills display, a mini-game, and a contact form for potential collaborations.

## Features

- **Hero Banner**: A visually appealing introduction with my name, profession, and call-to-action buttons.
- **About Me**: A detailed background including my career timeline and achievements.
- **Projects**: A showcase of my major projects with interactive cards.
- **Skills**: A display of my technical skills with progress indicators.
- **Mini-Game**: An interactive game that users can play directly on the portfolio.
- **Contact Form**: A user-friendly form for inquiries, complete with social media links.

## Technologies Used

- **React**: For building the user interface.
- **Tailwind CSS**: For styling and responsive design.
- **Framer Motion**: For animations and transitions.
- **TypeScript**: For type safety and better development experience.

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/tarosh-mathuria-portfolio.git
   ```
2. Navigate to the project directory:
   ```
   cd tarosh-mathuria-portfolio
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm start
   ```
5. Open your browser and visit `http://localhost:3000` to view the portfolio.
